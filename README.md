# Dante's Inferno: Circulus Nonus

2D-платформер по мотивам девятого круга «Божественной комедии»: перемещение, бой, ловушки и встреча с боссом.

**C# · .NET 8 · MonoGame DesktopGL · MVC-inspired structure**

## Что находится в репозитории

- `DanteGame/Controller/Game1.cs` — игровой цикл, состояния и создание уровней.
- `DanteGame/Model/` — игрок, противники, платформы, ловушки, бонусы и портал.
- `DanteGame/View/` — меню и пролог; `GameView.cs` — представление.
- `SaveData.cs`, `SoundManager.cs` — сохранения и звуковые эффекты.

## Статус сборки

В текущем checkout **нет каталога Content и manifest `Content.mgcb`**. Код обращается к текстурам `Sprites/*`, шрифтам `Fonts/*`, музыке и звукам. Поэтому полноценный запуск из одного клона сейчас не воспроизводится. Настройки Visual Studio не заменяют эти ресурсы.

Для восстановления запуска нужны исходные ассеты с правом распространения, их content manifest и настройка MonoGame Content Pipeline. После восстановления ресурсов:

```sh
cd DanteGame
dotnet tool restore
dotnet restore DanteGame.csproj
dotnet run --project DanteGame.csproj
```

Нужны .NET 8 SDK и поддерживаемая графическая среда DesktopGL. Сборка и GUI-запуск при текущей очистке не подтверждены.

## Управление по исходному коду

| Клавиши | Действие |
| --- | --- |
| A / D или ← / → | Перемещение |
| Space | Прыжок |
| E / J | Атака |

## Тесты и следующие шаги

`Tests/GameTests.cs` содержит учебные проверки, многие из которых проверяют локальные переменные, а не реальные игровые объекты. Они не доказывают корректность физики или игрового цикла.

Приоритеты: вернуть content assets, отделить тестовый проект от игры, заменить проверки на тесты реальных моделей, добавить воспроизводимую сборку. Кэши `.vs`, `bin`, `obj` и локальные настройки IDE исключены из Git.
